# 远程连接入口 Spec：暂时隐藏

## 背景与决策

SSH 远程工作区的连接流程包含「部署远程运行时资源」一步，
资源包按版本号从 CDN 下载；目前**没有 Skcode 自有的远程资源源**，
该步骤必然失败，入口留着会误导用户。

决策（产品侧）：**暂时隐藏「远程连接」全部入口**，隐藏而非删除——
链路、SSH 实现（ssh2）和已有远程工作区的重连能力全部保留。

## 状态所有者

- 单一策略点：`useRemoteConnectionEntryVisibility()`（恒返回 `false`）。
  ChatEmptyState 工作区菜单、WorkspaceSidebar 项目菜单全部走它，
  与其它入口不分叉（Tray/应用菜单本就无此入口）。
- 已存在的远程工作区会话、侧边栏重连按钮不受影响（它们不是"新建连接"入口）。
- 通过打开 WSL/UNC 路径触发的内部远程对话框不属可见入口，保持现状。

## 恢复条件

接入自有远程资源源（静态资源服务器 + 按版本目录结构）
或确认可复用的资源分发方案后，把 `useRemoteConnectionEntryVisibility`
改回 `true` 即可恢复全部入口，无需其它改动。

## 验收场景

1. 空态工作区菜单（打开文件夹 / 不在项目中工作）不再出现「远程连接」。
2. 侧边栏项目菜单不再出现「远程连接」。
3. 已有远程工作区的重连入口保留可点。
4. Web 端行为不变（本就隐藏）。
